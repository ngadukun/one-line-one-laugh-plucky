One funny line, 200 characters or fewer, written by a tiny from-scratch program for the [One Line, One Laugh](https://make.fun/c/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) bounty on make.fun.

## The line

> I asked my smart speaker for motivation — it read my bank statement out loud.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`), validating that it is a single line of 1–200 characters.
